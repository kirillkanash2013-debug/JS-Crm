Подключение профиля

Откройте Ads Manager один раз в этом браузерном профиле, дождитесь загрузки и нажмите «Подключить соц». После обнаружения списка кабинетов отдельные вкладки не нужны.

Экспериментальное подключение через доступ, уже загруженный страницей Ads Manager. Работоспособность зависит от этой сессии и разрешений Meta. Доступ хранится локально до закрытия браузера.

Подключить через токен Facebook / FBacc

Если FBacc уже получает токен для этого соца, скопируйте его и вставьте здесь. Откройте Ads Manager того же соца перед подключением. Один токен используется для всех доступных ему кабинетов.

Токен хранится только локально до закрытия браузера. Поле очищается после отправки. Демо-ключ подписки вводится отдельно.

Статистика всего соца

Кабинеты собираются последовательно, период — по часовому поясу каждого кабинета. Изменение рекламы пока не подключено.
